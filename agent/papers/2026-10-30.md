## 3. Learning to Formulate: Agentic Hardware-Software Co-Design of AI Infrastructure through Progressive Optimization and Verification / 学习制定：通过渐进优化和验证实现人工智能基础设施的代理硬件-软件协同设计

<details><summary><b>Abstract / 摘要</b></summary>

<details><summary><b>Abstract / 摘要</b></summary>

A2A and MCP authenticate the channel, but the sender is the party in doubt, so a prompt-injected agent can launder fabricated facts and authority through a multi-agent system. We present Proof-Carrying Messages (PCM), a protocol in which each claim carries evidence: records from an append-only Merkle log that the agent cannot write, with inclusion proofs, signed by an attesting signer the agent cannot control. <details><summary><b>Abstract / 摘要</b></summary>

Large language models are pretrained on vast, uncurated corpora scraped from the public web. This creates a security risk from attackers who plant poisoned content in the pretraining data. ## 35. Heads of Security: Learned Attention Gates Improve Prompt Injection Robustness / Heads of Security: Learned Attention Gates Improve Prompt Injection Robustness

<details><summary><b>Abstract / 摘要</b></summary>

We introduce Heads of Security (HoS), a prompt injection defense that enforces instruction-data separation via a small set of learned per-head attention gates. HoS learns how each head should redistribute attention between trusted and untrusted tokens, enabling models to reason over untrusted content without following injected instructions. On agentic benchmarks with static attacks, HoS and SecAlign perform similarly and substantially improve the security-utility trade-off over the base model. ASIDE struggles with tool use, achieving only 10% utility. These results show that prompt injection robustness can be achieved and improved through targeted attention interventions.

<details><summary><b>Abstract / 摘要</b></summary>

As executable environments for language agents scale, generating and verifying their rollouts becomes increasingly expensive. To address this question, we introduce EnvSched (Environment-aware Scheduling), an online scheduler that learns from rollout history.
