## 1. RubricWorld: World Model-Guided Rubric Optimization for LLM Graders / RubricWorld ：法学硕士评分者的世界模型引导式评分标准优化

**Date**: 2026-11-01 | **arXiv**: [2611.01986v1](http://arxiv.org/abs/2611.01986v1) | **PDF**: [Link](http://arxiv.org/pdf/2611.01986v1)

**Categories**: cs.AI

<details><summary><b>Abstract / 摘要</b></summary>

Rubric optimization improves LLM grading by revising scoring instructions while keeping the grader's parameters fixed. Existing optimizers often judge edits by aggregate validation performance, limiting the supervision they retain about which errors an edit corrects or introduces. Testing each candidate also requires rescoring validation answers, which limits how many edits can be explored within a fixed budget. We propose RubricWorld, a framework that learns from previous edit evaluations to guide further search. Its world model predicts an edit's correction and degradation rates at score boundaries, conditioned on the current rubric state. The training signal comes from paired grading results: scores for the same answers before and after an edit. Predictions select one candidate for direct evaluation, and held-out confidence bounds determine whether it corrects enough target errors while keeping new errors within prespecified limits. Measured effects update the model even when the edit is rejected. Across EIR (National), ASAP2.0, and ASAP-SAS with three frozen LLM graders, RubricWorld achieves the highest score in 20 of 27 metric comparisons. On ASAP2.0, it raises gpt-5-mini accuracy from 18.20% with the original rubric to 46.70%, exceeding the strongest baseline, APO, by 22.60 percentage points. code will be released upon acceptance.

<details><summary><b>Abstract / 摘要</b></summary>

A model can therefore represent physical information and respond to incorrect actions without its native prediction error reliably measuring physical surprise.

## 8. SCOUT: Planning under Occlusion via Object-Centric World Model Rollouts / SCOUT ：通过以对象为中心的世界模型推出在遮挡下进行规划

**Date**: 2026-11-01 | **arXiv**: [2611.01600v1](http://arxiv.org/abs/2611.01600v1) | **PDF**: [Link](http://arxiv.org/pdf/2611.01600v1)

**Categories**: cs.RO, cs.AI, cs.CV

<details><summary><b>Abstract / 摘要</b></summary>

Robots manipulating in cluttered spaces must often plan from partial views where foreground objects occlude the target, surrounding geometry, and usable free space. Reactive policies often miss these hidden constraints, while exhaustive search becomes computationally prohibitive in dense clutter. We present SCOUT, an occlusion-aware planning framework that bridges high-level deliberation with grounded physical rollouts. SCOUT leverages an object-centric scene representation to reconstruct hidden geometry and derive a relational planning state capturing blocker hierarchies and accessibility corridors. To navigate the vast action space in clutter, an LLM proposes structured action candidates which are then rigorously evaluated via Monte Carlo Tree Search (MCTS) using a learned action-conditioned world model.
